# QA Scooter — автотесты для учебного сервиса Яндекс.Самокат

Финальный проект 4 спринта курса «Инженер по тестированию» Яндекс Практикум.

## Что покрыто

- Раздел «Вопросы о важном» — параметризованный тест на все 8 вопросов FAQ.
- Позитивный сценарий заказа самоката — параметризованный тест:
    - 2 точки входа (верхняя и нижняя кнопки «Заказать»);
    - 2 разных набора данных.

## Стек

- Java 11
- Maven
- JUnit 4
- Selenium WebDriver 4
- WebDriverManager

## Структура

```
src/
├── main/java/pageobjects/
│   ├── MainPage.java        — Page Object главной страницы
│   └── OrderPage.java       — Page Object формы заказа
└── test/java/tests/
    ├── BaseTest.java        — настройка драйвера и tearDown
    ├── FaqTest.java         — тесты FAQ (параметризованные)
    └── OrderTest.java       — тесты заказа (параметризованные)
```

## Как запустить

```bash
mvn test
```

Тесты запускаются в Google Chrome. Чтобы переключиться на Firefox,
раскомментируй соответствующий блок в `BaseTest.java`.
